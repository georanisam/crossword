선생님용과 학생용 화면이 따로 있어요. 선생님은 퀴즈를 만들고, 학생은 받은 링크로 풀기만 하면 됩니다.

✏️ 선생님용 — 퀴즈 만들기

웹앱 주소로 접속하면 바로 만들기 화면이에요.

  1. 기본 설정
    칸 수(5×5·7×7·10×10·직접입력)와 주제를 적고, 난이도(쉬움·보통·어려움)를 고릅니다.
  2. AI로 단어·힌트 생성
    「✨ AI로 단어·힌트 생성」을 누르면 주제에 맞는 단어와 설명이 자동으로 만들어져요. (직접 추가도 가능)
  3. 단어 · 힌트 편집
    단어나 힌트를 자유롭게 수정·추가·삭제. 빈 힌트는 ✨ 버튼으로 AI가 채워줍니다.
  4. 자동 배치
    「🧩 자동 배치」를 누르면 단어들이 교차하며 퍼즐이 완성돼요. 마음에 안 들면 「🔀 다시 배치」로 다른 모양을 만들 수 있어요.
  5. 저장하기
    퀴즈 이름을 적고 저장. 분류(폴더)를 적어두면 나중에 찾기 쉬워요. (예: 1학기, 3단원)
  6. 배포 (둘 중 택1)
    • 종이로: PDF·Word 출력 (빈칸=학생용 / 정답=교사용, 학생용엔 학번·이름 칸 자동)
    • 온라인으로: 🔗 학생용 공유 링크 + QR코드 생성 → 학생에게 전달
📚 저장된 퀴즈에서 편집·복제·삭제 📊 제출 현황·평균 점수 확인 📈 단어별 정답률(많이 틀린 단어) ⬇ 제출기록 CSV 다운로드
📈 단어별 정답률은 「제출 현황」 탭에서 위쪽 드롭다운으로 특정 퀴즈를 선택하면 제출자 목록 위에 나타나요. (전체 퀴즈 상태에서는 안 보여요. 불러오는 데 몇 초 걸릴 수 있어요.)

🧑‍🎓 학생용 — 풀고 제출하기

선생님이 준 링크(또는 QR)를 누르면 시작돼요. 설치 필요 없이 폰·PC 모두 가능.

  1. 학번 · 이름 입력 후 시작
  2. 단서를 누르고 단어 입력
    가로 단서는 1·2·3, 세로 단서는 ㄱ·ㄴ·ㄷ 으로 표시돼요. 칸이나 단서를 눌러 그 단어를 쭉 타이핑하면 자동으로 채워집니다.
  3. 제출하고 채점 받기
    제출하면 바로 점수가 나와요. 맞은 칸은 초록, 틀린 칸은 빨강으로 표시되고 정답도 보여줘요.
  4. 다시 풀기 가능
    수정해서 다시 제출할 수 있어요. 결과는 선생님께 자동으로 기록됩니다.

💡 알아두면 좋아요

화면 크기퍼즐은 PC·태블릿에선 크게, 모바일에선 화면에 맞게 자동 조절돼요.
한글 입력받침까지 자연스럽게 입력돼요. 단어 단위로 쭉 입력하면 됩니다.
공유 링크퀴즈마다 링크가 달라요. 같은 링크는 여러 명이 동시에 풀어도 괜찮아요.
출력PDF·Word 모두 A4 한 장에 맞춰 자동 크기조정됩니다.
처음엔 주제 입력 → AI 생성 → 자동 배치 → 저장 → 공유 순서로 한 번만 만들어보면 금방 익숙해져요. 🙂
